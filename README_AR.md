# تطبيق كورسات Flutter

## نظرة عامة
تطبيق كورسات Flutter هو تطبيق تعليمي يهدف إلى تسهيل الوصول إلى الدورات التعليمية والمواد الدراسية للطلاب. يوفر التطبيق واجهة سهلة الاستخدام لعرض الكورسات، المواد، الفيديوهات، وإدارة الحساب الشخصي.

## الميزات الرئيسية
- استعراض الكورسات والمواد الدراسية
- مشاهدة الفيديوهات التعليمية
- إدارة الملف الشخصي وتعديل البيانات
- نظام تسجيل الدخول والتسجيل للمستخدمين
- مركز المساعدة وسياسة الخصوصية

## التقنيات المستخدمة
- **Flutter**: لبناء واجهات المستخدم متعددة المنصات (Android، iOS، Web، Linux)
- **Dart**: لغة البرمجة الأساسية للتطبيق
- **GetX**: لإدارة الحالة والتنقل بين الصفحات
- **REST API**: للتواصل مع الخادم وجلب البيانات
- **تصميم متجاوب**: يدعم جميع أحجام الشاشات

## هيكل المشروع
- `lib/`: يحتوي على الكود الأساسي للتطبيق
  - `controllers/`: إدارة منطق التطبيق
  - `model/`: نماذج البيانات
  - `services/`: خدمات الاتصال بالخادم
  - `ui/`: الشاشات والواجهات
  - `core/`: الثوابت والمساعدات
- `assets/`: الصور والأيقونات
- `test/`: اختبارات التطبيق

## طريقة التشغيل
1. تثبيت [Flutter](https://flutter.dev/docs/get-started/install)
2. تشغيل الأمر:
   ```bash
   flutter pub get
   flutter run
   ```
